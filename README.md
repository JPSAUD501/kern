# Kern

An open source Android keyboard that types in every language you speak, swipes as well as the best proprietary keyboards, and keeps what you type on your phone.

> **Status:** early development. Nothing to install yet.

- **Multilingual without switching.** Enable several languages and mix them in the same sentence.
- **Swipe typing** with a neural decoder trained on open data.
- **Offline core.** Typing, correction, prediction and swipe run on the phone.
- **AI help under your control.** Rewrite, translate, proofread and dictate through your own OpenRouter account, with a preview before anything changes, and a screen that lists every request that left the phone.
- **Free and open source.** No ads, no tracking, no account.

See [docs/product.md](docs/product.md) for the vision and quality bars, [docs/decisions.md](docs/decisions.md) for the architecture, and [docs/roadmap.md](docs/roadmap.md) for the plan. Contributors and agents start with [AGENTS.md](AGENTS.md).
